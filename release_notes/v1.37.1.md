**If JRiver has stopped, 24bit7 now starts it again for you.**

When JRiver crashed, asking Alexa for a playlist got "I can't find the Sonos zone in JRiver", which sent you looking in the wrong place. Now Alexa says "JRiver wasn't running, so I've started it, uno momento", and your request plays by itself once JRiver is ready. A build from the main window does the same before it runs.

- Only a JRiver on this PC is started. If JRiver is running but not answering, 24bit7 leaves it alone and Alexa says she couldn't reach it.
- Stop and pause never start JRiver, and Non-stop doesn't either.
- Nothing to change in the Alexa console.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
