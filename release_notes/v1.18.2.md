**If All Else Fails' spoken message is now an option, off by default.** When a voice command or keyboard shortcut found nothing, 24bit7 explained why in the room before the fallback played, using a short WAV file made with Windows' own voice. That file showed up in Playing Now, and its 22 kHz sample rate could catch out some DSP setups (reported by mandrews79). It's now a tick box, **Say why in the room first**, under If All Else Fails in Settings > Playlist. It's one setting for every playlist type, and off to start. The console still says why either way.

- If you relied on hearing the message by voice, tick **Say why in the room first** after upgrading.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
