**Last.fm now works out of the box, with no key to find.** 24bit7 comes with a Last.fm key built in, so a fresh install builds Similar Artists playlists from Last.fm and Similar Tracks playlists from Last.fm and YouTube Music straight away.

- **Your own key still wins.** If you've already put a Last.fm key under Settings > Keys, 24bit7 keeps using it. You can also clear it and use the built-in one.
- **Your settings stay as they are.** The new starting sources only apply to a fresh install. To use them on an existing one, tick Last.fm for Similar Artists, and Last.fm and YouTube Music for Similar Tracks, under Settings > Sources.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
