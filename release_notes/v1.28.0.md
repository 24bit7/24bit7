**24bit7 now tells you when there's a new version.**

Each time 24bit7 opens, it asks GitHub for the latest release. If it's newer than yours, a line in the console says so, with a link to the download. When you're up to date, or offline, it says nothing, and there's no setting to switch on. This version is the first to check, so you'll hear about the next one.

- **Test My Sources:** if the test finished while a playlist was building, its "Source test ready" line landed in the middle of the build's lines. It now waits until the build has finished and comes just after its Done line.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
