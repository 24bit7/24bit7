**Profiles now hold the zones, and each profile can have a keyboard shortcut of its own.** Both were asked for by datdude, who runs a stereo set-up and a surround one from the same library, with a remote from the sofa.

- **Zones in profiles**: a profile now holds the Default zone and the Follow tick under Settings > Other > Zones, and the zone the keyboard shortcuts apply to, so a surround profile plays to a different zone from a stereo one. Which zones are shown stays with the PC. A profile saved before this release leaves the zones as they are until you save it again.
- **A shortcut per profile**: Settings > Other > Keyboard Shortcuts has a Load box for each saved profile, under Switch Profiles. Pressing it loads that profile and restarts 24bit7, with JRiver still playing. Pressed when that profile is already loaded, it does nothing, so a remote or an automation always lands on the profile it means. Switch Profiles still steps through them A to Z.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
