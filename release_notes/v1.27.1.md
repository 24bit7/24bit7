**If JRiver turns 24bit7 away, 24bit7 now tells you why and how to fix it.**

Recent versions of JRiver can refuse other programs until a username and password are set, even on the same PC. 24bit7 used to report this as "JRiver isn't reachable" followed by a puzzling error, and the zone lists stayed empty. Now the console says JRiver turned 24bit7 away. It also says where to set a login in JRiver (Tools > Options > Media Network > Authentication) and that the same login goes in Settings > Keys. If JRiver isn't answering at all, the console says to check that it's running with Media Network on, and to set the JRiver host if JRiver is on another PC.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
