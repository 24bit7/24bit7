**Review says why each track is there, and the Moderator works again with Anthropic, now on Claude Haiku 5.5 at about a tenth of the cost.**

Review has a Found By column: which sources suggested each track, or Seed, Deep Cuts or AI, and resting the pointer on it gives the whole story, such as "Last.fm named Staind as like 3 Doors Down - When I'm Gone." Since October the Moderator hadn't run for anyone using Anthropic: an update to the package 24bit7 talks to Claude with dropped a setting the Moderator used, so every check stopped before it was sent. The console said "Moderator didn't run", but the Log said "0 removed", which looked like it had run and found nothing. Both are fixed, and the Log now says "didn't run" for those older builds too. The Moderator, the usage question in AI Usage and AI Playlist's quick opener now use Claude Haiku 5.5, which costs about a tenth as much as Haiku 4.5 and answers in about half the time. Its answers can vary a little between runs on the same tracks.

- When 24bit7 opens, a source that had trouble answering in each of your last three builds gets a line in the console, pointing to Test My Sources.
- The line that says a new version is out now gives its headline too.
- Play & Embellish has a Non-stop column beside Shuffle, Deep Cuts and the Moderator. It starts as Artist Matching's Non-stop was, so nothing changes at the upgrade.
- "Multiroom" by voice works from either room: with only the main system playing, the music moves to the Sonos and the main system follows it.
- Blend shows up in Discover like any other build.
- The console heads each build with what kind it is, Artist Matching or Track Matching, and the Log uses the same names.
- Discover's tables: number columns fit their titles at any display scaling, numbers are centred, and every other row is shaded.
- The arrow that opens the console's tabs no longer covers the first line of the console.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
