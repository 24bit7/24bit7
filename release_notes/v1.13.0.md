**A new look.** The dark theme goes black and green throughout: a black strip across the top, solid header bars on every Settings section and table, and green tick boxes. The light theme gets the same layout in blue and grey. Both now look the same on any PC.

**A built-in title bar.** The Play, Discover and Settings tabs run to the top of the window, with minimise, maximise and close at the right. Drag the strip to move the window and double-click it to maximise. Prefer Windows' own? Settings > Other > Use the Windows title bar.

**Switch to a Sonos without starting again.** Switching to a DLNA zone now carries on from the same point in the song. Fine-tune it with Settings > Voice Commands > Switch Timing Adjustment.

**Keep It Tight.** Drift is now Off, Keep It Tight (stays within two steps of your seed) or Spread. Non-stop is Off, Keep It Tight (each top-up reseeds from the original playlist) or Let's See Where This Goes. JRiver playlists get a Whole playlist option under Reseed from.

**A sharper AI Moderator for Drift.** Drift can have its own moderator level, the moderator compares each track with the playlist so far as well as the seed, and when most of what one seed brought in goes off course, the rest of it goes too.

**AI Usage.** Settings > Keys shows the tokens each AI feature has used, with estimated costs, a guide to what each one costs per run, and a Query that suggests ways to use fewer. Tick it to show the total in Now Playing.

**More variety from Similar Tracks.** The same seed no longer gives the same tracks every time.

- Set as Default buttons on JRiver Playlists copy the global rows into the playlists shown, and new playlists start with them.
- Titles with a dropped "g" now match, so Smokestack Lightnin' finds Smokestack Lightning.
- Keep the cache for 1 month, 1 year or permanently, and clear it by age (Settings > Other).
- Discover opens on the latest session, with a tidier layout. The Label button is now an option under Settings > Search Sites.
- Support replaces Buy me a coffee.
- Running the tests no longer changes the Start with Windows setting.

Thanks to datdude on the JRiver forum, whose feedback is behind several of these.

**Upgrading:** unzip to a new folder and copy your .env and 24bit7.db across. The Alexa skill hasn't changed this time.
