**24bit7 can update itself: the new-version note lists everything that's new since yours, and Update Now does the rest.**

When a newer version is out, the console now lists every release since the one you have, newest first, each with its headline, so you can tell at a glance whether it's worth updating. Underneath are **Update Now**, **Release Notes** and **Hide**. Update Now asks first, downloads the new version beside your 24bit7 folder, checks it against the fingerprint published with the release, then closes 24bit7, swaps the folders and starts it again, in about a minute. Your .env, 24bit7.db, profiles and logs come across, and your old copy is kept beside it as, say, "24bit7 1.38.0 backup". If anything stops it part-way, the old copy is put back and the console says what happened. Update Now first appears when the version after this one comes out.

- **Restore JRiver**, under Settings > Other: what a voice request or a build does when JRiver on this PC isn't answering. **Start If Closed**, the default and what 1.37 did, starts JRiver's Media Server and carries on. **Off** tells you instead, for when JRiver stopping may be a sign of something else. **Start If Closed, Restart If Hung** also closes a JRiver that's running but hasn't answered for ten seconds and starts it again; a forced close while JRiver is writing its library could damage it, so keep JRiver's automatic library backups on.
- Alexa now says which it is: "JRiver isn't running on the media PC" or "JRiver's running but not answering", rather than that she can't find the zone.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
