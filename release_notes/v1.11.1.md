**Saved Playlists global rows now save.** Changes to the All playlists and All smartlists rows, on Windows (Main) or a device tab, were lost when the page rescanned your playlists from JRiver. They now stick through tab switches, closing to tray and restarts. If you set these rows in an earlier version, set them once more after upgrading.

**Upgrading:** unzip to a new folder and copy your .env and 24bit7.db across from the old one.
