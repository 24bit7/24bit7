**The DAC profile is named for what it was measured on: a Chord Hugo TT.**

The Multiroom DAC profile, the manuals, the README and the Settings note said Chord Hugo; the kit it was measured on is a Hugo TT. Any Chord Hugo still matches the profile, since JRiver and the ASIO driver don't say which model, so another Hugo should run Calibrate rather than trust the numbers. Nothing else changes.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
