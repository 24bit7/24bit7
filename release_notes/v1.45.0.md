**A phone the router gives a new address is found again, and 24bit7 asks when it can't tell which phone is answering.**

Ben's phone got a new address from the router and the Devices tab never came up, as 24bit7 only looked where it last found it. Now it looks across your home network when it starts and every five minutes. The phone app keeps who it is and its code through a reinstall, and if a phone still can't be told (a reset, a new phone, or one not added yet), the Devices tab comes up and asks which of your phones it is, with its code.

- **Settings > Other > Devices**: On or Off, so a phone charging by USB needn't bring the Devices tab up, and **+ Add a Device...**, which opens the tab, to add a phone before anything has been copied to it.
- **Search's stack settings**: **# Tracks** is a box you type a number in, one to twenty, then Select From Hits, then Go, under a green **Stack Settings** heading. Pressing Enter with nothing typed no longer pops up "Type an artist first."
- **Update the phone app** from this release's page, over the old one.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
