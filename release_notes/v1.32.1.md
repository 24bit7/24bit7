**The needle drop skill's interaction model pastes into the Alexa console without a warning.**

Pasting 1.32.0's interaction model warned that the "query" slot in SongsByIntent "cannot reference more than one slot type", and the model wouldn't build. The Radio and Station commands from 1.31.0 had given that slot their own station type, and Alexa wants one slot name to mean one type across the whole skill. Radio and Station now have a slot of their own, and the skill's code reads either. Nothing else changes.

If you've already pasted the 1.32.0 model and hit the warning, paste `alexa\interaction_model.json` from this release into the JSON Editor (empty it first), Save Model, Build Model, then paste `alexa\lambda_function.py` into the Code tab and Deploy. The manual's Upgrading section has the steps.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
