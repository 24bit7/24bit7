**Review says plainly when a saved playlist comes out empty.** If JRiver made the playlist but wouldn't add the tracks to it, Review showed a long error with JRiver's whole web address, which was easy to miss, so it wasn't clear why the new playlist was empty. Now it names the playlist and says it's empty. When JRiver refused access, it also suggests checking the Media Network username and password in Settings > Keys.

**Upgrading:** unzip to a new folder and copy your .env, 24bit7.db and profiles folder across from the old one.
